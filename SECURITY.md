# Security Policy

This repository contains the instructions of a coding-agent skill and a zero-dependency validator. Security issues include guidance that would lead an agent to leak secrets, execute untrusted code, obey instructions embedded in a reviewed change, or post sensitive details publicly, as well as flaws in `validate-review.cjs`.

Please report vulnerabilities privately, either through GitHub's **Report a vulnerability** button on the repository's Security tab or by email to contact@ogw.fr. Do not open a public issue for a security report.
